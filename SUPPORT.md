# Support

Use [Discussions](https://github.com/Alien6-Studio/keycloak-bounded-delegation/discussions)
for design questions and integration help. Use the issue templates for reproducible
bugs and feature proposals. Include the extension revision, exact Keycloak/JDK
versions, cache topology and a synthetic configuration, with credentials removed.

Use [SECURITY.md](SECURITY.md) for private vulnerability reporting. Do not put
security-sensitive reports, real tokens, keys or tenant data in public tickets.

This experimental project is maintained on a best-effort basis. Its current
qualification window is in [compatibility.json](compatibility.json); there is no
production SLA or independent backport branch. Official Keycloak questions and
proposals should use the [Keycloak community](https://www.keycloak.org/community)
and its contribution process.
