# Community conduct

Treat participants respectfully. Discuss concrete technical behavior and evidence;
avoid personal attacks, harassment, discrimination and disclosure of another
person's private information. Welcome questions, corrections and contributors
with different experience levels.

These expectations apply to issues, discussions, pull requests and other spaces
maintained by this project. Report conduct concerns privately to
[contact@alien6.com](mailto:contact@alien6.com). The repository maintainer reviews
reports confidentially, requests clarification where needed and can moderate
content or restrict participation proportionately. A report concerning the
maintainer can be escalated to Alien6 Studio through the same organizational
contact. This project does not appoint Keycloak maintainers as its moderators.
